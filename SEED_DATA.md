# Sample Venues - Seed Data

## Overview
The seed script adds 12 diverse venues across major US cities to populate the database.

## How to Run
```bash
cd backend
npm run seed
```

This command will:
1. Connect to MongoDB
2. Clear any existing venues
3. Add 12 sample venues
4. Display a summary of added venues
